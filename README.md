# Laboratorio 4 – Base de Datos Austral Editores
## Sistemas de Información para la Gestión (ICN292)
**Estudiante:** Javiera Pino  
**Universidad:** Universidad Técnica Federico Santa María
## Descripción del proyecto
El presente repositorio contiene el desarrollo del Laboratorio 4 de la asignatura Sistemas de Información para la Gestión (ICN292). El trabajo consiste en la creación e implementación de una base de datos relacional para Austral Editores, utilizando MySQL.
## Contenido del repositorio
- `ICN292-Lab4-Pino-Javiera.sql`: script SQL con la creación y desarrollo de la base de datos.
- `Diagrama_ER_Austral.png`: diagrama entidad-relación de la base de datos.
- `ICN292-Lab4-Pino-Javiera.docx`: informe del laboratorio en formato Word.
- `ICN292-Lab4-Pino-Javiera-pdf.pdf`: informe del laboratorio en formato PDF.
## Estructura de la base de datos
La base de datos se denomina `austral` y está compuesta por cuatro tablas principales:
- `autores`
- `libros`
- `colecciones`
- `pagos`
Se establecieron claves primarias y claves foráneas para relacionar las tablas y mantener la integridad de los datos.
## Desarrollo del laboratorio
Se realizaron diez consultas SQL que permiten trabajar con la información almacenada mediante operaciones de selección, filtrado, agrupación, ordenamiento, inserción, actualización, eliminación y unión de tablas.
También se implementaron relaciones entre autores, libros, colecciones y pagos, comprobando el funcionamiento de la base de datos mediante consultas en MySQL Workbench.
